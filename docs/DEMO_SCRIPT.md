1. **Opening (20s):** show the offline/local status and explain that low concern is not a safety guarantee.
2. **URL (45s):** load the editable `DEMO ONLY` IP-host URL. Show evidence such as IP host and credential terms, then explain it was never opened.
3. **SMS (45s):** load the editable synthetic urgent OTP/payment message. Show the classifier/rule mode and practical advice.
4. **Network (45s):** upload `fixtures/network-DEMO-ONLY.csv`. Show the bounded schema, aggregate count, and row-level anomalies; stress that unusual is not confirmed intrusion.
5. **Privacy and diagnostics (35s):** enable/clear history to show only summaries are kept; show model/runtime fields.
6. **Llama path (30s):** only if `scripts/verify_llama.py` succeeded on the demo device, show the four readiness fields and a live `llama-executorch` response. Otherwise show template mode and state the external model-access/runtime blocker truthfully.

Capture a fresh screen recording from the target device. Do not present synthetic fixtures, mocked tests, or a model-file check as live Llama inference.
